# Investigate

Identify the question, relevant platform and framework, and the OS or SDK version when it matters. Open the matching topic and the smallest Apple source that answers the question.

For behavior that differs across environments, compare the API contract with the observed behavior. Check [Apple Developer Updates](https://developer.apple.com/documentation/updates) and [Technotes](https://developer.apple.com/documentation/technotes) when a release could explain the difference. Report what the sources establish, what you observed, and any remaining uncertainty.
